# ✅ Project 07 - Assertions & Validation

## 📖 Overview

This project demonstrates how to validate different elements of a web application using Selenium assertions.

## 🌐 Application Under Test

https://www.saucedemo.com

## 🚀 Test Scenario

- Login with valid credentials
- Validate URL
- Validate Products page title
- Add product to cart
- Validate cart badge
- Open cart
- Validate product name

## 🛠 Technologies Used

- Python
- Selenium WebDriver
- Chrome
- PyCharm

## ✅ Assertions Used

- URL Assertion
- Page Title Assertion
- Cart Badge Assertion
- Product Name Assertion

## 📂 Skills Demonstrated

- Selenium Automation
- Python Assertions
- Explicit Waits
- UI Validation
- End-to-End Testing
